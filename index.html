07 Артефакты как код07 / 20

Анатомия task-файла = контракт для одного

tasks/epic-wsdl/task-03-recursive-parse.md · model: sonnet
## Факты
парсер WSDL — src/wsdl/parse.ts:118
## Шаги
1. добавить рекурсию по import — parse.ts:140
2. защитный лимит глубины = 32
## Что НЕ делать
✗ не трогать сетевой слой · ✗ нет «примерно / если возможно»
## DoD
npm run test:wsdl → PASS ✓ (corpus 12/12)
  • Факты → шаги с файл:строка — никакой воды
  • «Что НЕ делать» — границы важнее задач
  • DoD одной machine-readable командой
  • Запрещены «примерно / если возможно»
  • Модель исполнителя указана явно

Такой файл может выполнить любой агент — и это проверялось буквально: границы и DoD важнее описания задачи

10 Definition of Done10 / 20
