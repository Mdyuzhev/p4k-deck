# P4K Deck — ИИ в продуктовой разработке

Лекция для студентов «ИИ в продуктовой разработке: от автодополнения к командам агентов» (30 слайдов, три части: тренды и видение → живой проект Pe4King → твёрдая база под агентов). Standalone web-приложение, цифры из репозитория Pe4King на 19 октября 2026.

Предыдущая версия («Один человек + AI-команда», 20 слайдов, август 2026) — в истории git.

**Live:** https://mdyuzhev.github.io/p4k-deck/

## Структура

- `index.html` — сама презентация (слайды, стили, speaker notes)
- `deck-stage.js` — web component `<deck-stage>`: навигация, масштабирование, thumbnail rail, print-to-PDF

## Управление

- `←` / `→`, `Space`, `PgUp` / `PgDn` — навигация по слайдам
- `Home` / `End` — первый / последний слайд
- цифры — прыжок на слайд
- `R` — сброс на первый слайд
- Print → Save as PDF — экспорт по слайду на страницу

## Локальный запуск

Открыть `index.html` в браузере — сборка не требуется.
